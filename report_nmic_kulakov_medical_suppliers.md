### 2.2. Законодательные режимы закупок

### 2.3. Электронные торговые площадки (ЭТП)

Основные площадки, на которых размещаются закупки центра:  
- **ТЭК-Торг** — электронные аукционы по 44-ФЗ  
- **ЕАТ.РФ** — закупки малого объёма  
- Другие федеральные ЭТП (РТС-Тендер, Сбербанк-АСТ, Фабрикант и т.д.)

### 2.4. Способы закупки

- **Электронный аукцион** — наиболее распространённый способ для стандартных товаров. Побеждает минимальная цена. Обеспечение заявки и контракта обычно ~10% начальной цены.
- **Закупка у единственного поставщика** — для срочных, уникальных или малых закупок.
- **Запрос котировок** — для закупок до определенного порога.

### 2.5. Категории закупок (по данным открытых агрегаторов)

Текущие закупки (июль 2026):  
- Поставка реактивов для патолого-анатомических отделений (~1.5–9.7 млн ₽)  
- Расходные материалы для отделения эстетической гинекологии и реабилитации (~2.9 млн ₽)  
- Расходные материалы для DaVinci Xi (~1.9–8.8 млн ₽)  
- Расходные материалы для инфузионной терапии (~3.6 млн ₽)

- Реактивы для клинико-диагностической лаборатории (~1.2–1.5 млн ₽)  
- Расходные материалы для научно-исследовательской деятельности (~0.9–3.0 млн ₽)  
- Натрия хлорид таблетированный для нужд аптеки (~0.8 млн ₽)  

**Видимый поставщик по ЗМО:** ООО «БиолоТ» — питательные среды для лабораторий.

## 4. РЕАЛИСТИЧНЫЕ ТОЧКИ ВХОДА ДЛЯ МАЛОГО ИП

### 4.1. B2C: Розничный магазин медицинских товаров для мам

**Концепция:** Компактный магазин/шоурум в пешей доступности от центра (улицы Академика Опарина, Ленинский проспект, Мичуринский проспект, район метро Университет).

**Почему это работает:**  
- Центр привлекает пациентов со всей России (583 участника форума из 106 городов по данным Telegram). Многие пациентки живут в стационаре или приезжают на консультации/ЭКО/роды без подготовленных товаров.  
- «Школа мам» и «День открытых дверей» собирают аудиторию, которая готова к покупкам.  
- Отсутствие ближайшей специализированной торговли создает «пустоту» на рынке.  

**Что продавать:**  
- Компрессионный трикотаж (класс 1 и 2) — послеродовой, антиварикозный  
- Молокоотсосы (Medela, Spectra, Ardo, Philips Avent) и аксессуары  
- Бюстгальтеры для кормления, накладки на соски  
- Бандажи, послеродовые пояса  
- Радионяни, детские термометры, весы  
- Ортопедические подушки для беременных и кормления  
- Товары для гигиены: прокладки, трусики, пеленки  

**Форматы:**  
- **Мини-шоурум (15–30 м²)** в арендуемом помещении рядом с метро Университет или на Ленинском проспекте.  
- **Онлайн-магазин + доставка в центр** — заказ через сайт/мессенджеры с курьерской доставкой на Опарина, 4.  
- **Pop-up точка** на мероприятиях центра (День открытых дверей, Школа мам) — по согласованию с администрацией.  

### 4.2. Партнерство с врачами (реферальная модель)

**Механизм:**  
- Индивидуальные врачи акушеры-гинекологи, неонатологи, маммологи, реабилитологи центра могут рекомендовать пациенткам конкретные товары (например, компрессионный трикотаж после кесарева, молокоотсос при лактационных проблемах).  
- ИП предоставляет образцы товаров врачам, каталоги, образовательные материалы.  
- Пациентка получает рекомендацию и покупает товар в магазине ИП или через доставку.  

**Юридические нюансы:**  
- Прямые откаты врачам — **незаконны** (ст. 204 УК РФ — коммерческий подкуп).  
- **Легальные формы:** спонсорство конференций центра, образовательные гранты, предоставление товаров для клинических нужд (например, для Школы мам или ГВ-Навигатора), размещение информации в пациентских буклетах центра как «рекомендованного поставщика».  

### 4.3. B2B: Поставщик для малых закупок (ЗМО)

**Механизм:**  
- Мониторинг закупок центра на zakupki.gov.ru, ТЭК-Торг, ЕАТ.РФ на предмет лотов ниже крупного порога.  
- Участие в закупках малого объема (до 500 тыс. ₽ для товаров по 44-ФЗ).  
- Примеры товаров для ИП: расходные материалы для гинекологических кабинетов, текстиль, мелкий медицинский инструментарий, специализированные среды и реагенты (если есть лицензия).  

**Требования для участия:**  
- Регистрация на ЭТП (ТЭК-Торг, ЕАТ.РФ и др.)  
- Электронная подпись (квалифицированная)  
- Регистрационные удостоверения на медицинские изделия (если применимо)  
- Наличие расчетного счета, отсутствие налоговых задолженностей  
- Для ИП — упрощенная система налогообложения (УСН) допустима, но некоторые заказчики предпочитают ООО  

### 4.4. Субподряд / партнерство с крупными дистрибьюторами

**Механизм:**  
- ИП становится поставщиком «последней мили» для крупного дистрибьютора, выигравшего тендер.  
- Например: крупный игрок выиграл тендер на компрессионный трикотаж, а ИП (имеющий магазин рядом с центром) обеспечивает экстренную подмену размеров, допродажи, доставку пациентам.

## 5. СТРУКТУРИРОВАННЫЕ РЕКОМЕНДАЦИИ ДЛЯ ИП «МЕДТЕХМАКС»

### 5.1. Краткосрочная стратегия (1–3 месяца)

1. **Провести полевую разведку:** посетить НМИЦ АГП им. В.И. Кулакова (Опарина, 4), изучить поток пациентов, выходы, ближайшую коммерческую инфраструктуру.  
2. **Проанализировать потребности:** поговорить с 5–10 пациентками (в Telegram-канале центра, в группах ВК/WhatsApp для беременных) — что они покупают, где, сколько тратят.  
3. **Выбрать нишу:** сфокусироваться на 3–5 товарных категориях (например: молокоотсосы + компрессионный трикотаж + бюстгальтеры для кормления).  
4. **Онлайн-пилот:** запустить Instagram-магазин / Telegram-канал / сайт с доставкой «в НМИЦ АГП им. В.И. Кулакова за 1 час».  

### 5.2. Среднесрочная стратегия (3–12 месяцев)

1. **Открыть шоурум (15–25 м²)** в арендуемом помещении на Ленинском проспекте или рядом с метро Университет.  
2. **Заключить договор с центром** на размещение буклетов/каталогов в отделениях акушерства, гинекологии, неонатологии (через отдел маркетинга/по работе с пациентами).  
3. **Предложить спонсорство** образовательным программам центра (Школа мам, ГВ-Навигатор) — поставка образцов молокоотсосов для демонстрации, информационная поддержка.  
4. **Получить регистрационные удостоверения** на медицинские изделия (если планируется B2B поставка в стационар).  
5. **Зарегистрироваться на ЭТП** и начать мониторить малые закупки центра (закупки малого объема).  

### 5.3. Долгосрочная стратегия (1–3 года)

1. **Масштабирование:** открытие точек у других федеральных перинатальных центров (Национальный медицинский исследовательский центр детской гематологии, онкологии и иммунологии имени Д. Рогачёва и др.).  
2. **Собственная торговая марка (СТМ):** разработка линейки товаров «для пациенток Кулакова» (послеродовые бандажи, подушки для кормления).  
3. **Прямые поставки в стационар:** участие в тендерах на категории, где малый бизнес конкурентоспособен (текстиль, ортопедические изделия, расходники для амбулатории).

## 7. ИТОГОВЫЙ ВЕРДИКТ

**Реалистичная и высокоперспективная модель для ИП «Медтехмакс»:**
1. **B2C розница** специализированных товаров для мам (молокоотсосы, компрессионный трикотаж, бюстгальтеры, бандажи, baby monitors) с точкой на Ленинском проспекте / у метро Университет и доставкой в центр.

**Рекомендуемый первый шаг:** запуск онлайн-магазина с доставкой «в НМИЦ АГП им. В.И. Кулакова» и тестирование спроса через рекламу в Telegram-канале центра и тематических сообществах беременных Москвы.
